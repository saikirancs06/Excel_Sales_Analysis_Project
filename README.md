# Sales Performance Analysis Using Microsoft Excel

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel to identify important business trends and performance indicators.

The analysis was performed to understand revenue trends, identify top-performing products, compare regional performance, and analyze monthly sales patterns.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel Formulas
* VLOOKUP / XLOOKUP
* Conditional Formatting
* Data Cleaning
* Data Analysis

## Analysis Performed

The project includes:

1. Data cleaning and preparation
2. Revenue and sales analysis
3. Monthly sales trend analysis
4. Product-wise performance analysis
5. Regional sales performance analysis
6. Identification of top-performing products
7. PivotTable-based analysis
8. PivotChart visualizations
9. Conditional formatting for identifying important trends
10. Lookup operations using VLOOKUP/XLOOKUP

## Key Insights

* Identified overall revenue and sales performance.
* Analyzed monthly revenue trends to understand changes in sales over time.
* Identified top-performing products based on sales and revenue.
* Compared sales performance across different regions.
* Used PivotTables and PivotCharts to summarize and visualize business data.
* Applied Excel formulas and lookup functions to improve data analysis and reporting.
